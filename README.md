# The 3AM Fridge Text

The one line a smart fridge texts its owner at 3am. `main.ts` (Node 22, standard library only) writes the line deterministically to `/output/entry.txt` — two runs produce byte-identical output.

The fridge has watched this 3am ritual before: the owner isn't hungry, they're standing in the fridge light thinking about an ex. The punchline lands on the fridge's own inventory — condiments, not closure. No milk, no ice, no door left open.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
